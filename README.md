# Freight Rate Prediction

> **Repository description:** A Python machine-learning pipeline for predicting freight load rates from lane, distance, equipment, weight, date, and market features.

This project trains a gradient-boosting model to estimate a posted freight rate for each load. It cleans and engineers shipment features, evaluates the model using time-ordered cross-validation, fits a final model on the labeled data, and creates predictions for the validation set. It also generates predictions for a fixed Lexington-to-Fort Wayne lane for each day of December 2025.

## What it does

- Corrects negative weight sign errors and flags capped or missing weights.
- Fills missing values using medians learned from the training data.
- Builds distance, geography, equipment, calendar, quote, and date-level market features.
- Evaluates with time-ordered validation folds so training periods precede validation periods.
- Fits an ensemble of histogram gradient-boosting regressors on log rates, including a robust model and a model trained after filtering suspected target outliers.
- Writes validation predictions and the December lane-rate predictions.
- Validates prediction-file formats and creates a chart for the December predictions.

## Setup and run

Run these commands from the project root.

### 1. Create an environment and install dependencies

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 2. Train and generate predictions

```bash
python src/train.py
```

The script reads `data/train_test.csv`, `data/validation.csv`, and `data/validation_predictions_template.csv`. It writes:

- `validation_predictions.csv` — one predicted rate for each validation load.
- `results/cv_metrics.json` — metrics from the time-ordered validation folds.
- `data/december_chart_inputs.csv` — one prediction per day for the fixed December route.

Training may take a few minutes depending on the machine.

### 3. Validate outputs and create the chart

```bash
python score.py \
  --predictions validation_predictions.csv \
  --december-predictions data/december_chart_inputs.csv
```

The scorer checks the prediction IDs, row count, column order, numeric values, and the 31 December dates and fixed lane inputs. It writes `scorer_results/candidate_december.png`. Final submission metrics are calculated by Spotter after submission.

To choose a different chart output directory:

```bash
python score.py \
  --predictions validation_predictions.csv \
  --december-predictions data/december_chart_inputs.csv \
  --output-dir path/to/output
```

## Model and evaluation notes

The training script uses a log-rate ensemble of two `HistGradientBoostingRegressor` models. One is fit after removing suspected outlier targets; the second uses absolute-error loss for robustness. Their log predictions are averaged and exponentiated to produce rates.

Cross-validation is chronological rather than randomly shuffled. The saved metrics include both all validation rows and a clean-target view that excludes suspected corrupted holdout targets. These offline metrics are for development and are not a substitute for final evaluation on a separate submission leaderboard.
